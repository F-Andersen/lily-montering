# LILY Montering

One-page static website for a furniture assembly and handyman service in Norway.

## What is included

- Responsive Norwegian Bokmaal landing page
- Services, audience, gallery, process, FAQ, and contact sections
- Optimized local project photos in `assets/images`
- Basic SEO metadata and Open Graph image
- Frontend-only lead form with a clear integration point

## Project structure

```text
.
├── index.html
├── styles.css
├── script.js
├── assets/
│   ├── favicon.svg
│   └── images/
└── foto/
```

## Run locally

Open `index.html` directly in a browser.

No build step or package installation is required.

## Before publishing

- Add the real phone number, email, business name, and service area if available.
- Connect the lead form to email, CRM, Netlify Forms, Formspree, or another endpoint.
- Add truthful LocalBusiness JSON-LD only after visible business contact data exists on the page.

## Assets

The gallery uses optimized copies of the provided work photos. Original files remain in `foto/`.
